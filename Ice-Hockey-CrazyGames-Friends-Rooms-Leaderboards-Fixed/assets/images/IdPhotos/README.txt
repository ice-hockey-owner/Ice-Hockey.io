Put your four profile photos in this folder. Supported formats: PNG, JPG/JPEG, WEBP, GIF and SVG.
You can name them 1, 2, 3, 4 (for example 1.png, 2.jpg, 3.webp, 4.png).
If a player has not uploaded a photo, the server randomly selects one of the images in this folder.
The included SVG files are only placeholders and can be replaced by your own photos.
